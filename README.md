# Naresh Kumar — Portfolio

A responsive personal portfolio website built with HTML, CSS and JavaScript.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a browser, or use VS Code Live Server.

## Before publishing
Personal links are already configured.

Optional files:
- Add `profile.jpg` for your profile photo.
- Add `resume.pdf` for the Resume download button.
- Update individual project links when each project has its own repository.

## Deploy
The site can be deployed easily using GitHub Pages, Netlify or Vercel.
